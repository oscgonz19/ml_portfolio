# From rocks to code

Personal site of Óscar A. González — geoscientist & data scientist.
Built as a digital field journal: real maps, field photographs and terrain data are the
visuals; projects are organized by question and place.

Next.js 14 · TypeScript · Tailwind · MapLibre. Deployed on Vercel.

```bash
yarn install
yarn dev
```

Content lives in `src/content/` (projects, about, field notes as markdown). See `CLAUDE.md`
for the structure and the design rules.
